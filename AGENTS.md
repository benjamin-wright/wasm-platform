# Agent guidance

## Working expectations

- Keep plans and documentation concise and practical.
- Use source code and repository documentation to describe current behavior. Keep `docs/todo.md` limited to active and upcoming work.
- Report validation results, review notes, and supporting evidence in the task conversation. Do not add per-task acceptance records, artifact inventories, or completed-work histories to the repository unless requested.

Read [.github/copilot-instructions.md](.github/copilot-instructions.md) for project navigation and [docs/standards.md](docs/standards.md) for coding, documentation, and testing conventions.
